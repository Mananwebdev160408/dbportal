# Product Context

## Register

brand

## Platform

web

## Users

Software engineers, DevOps leads, database administrators, and open-source developers who demand high-speed, zero-overhead local tooling.

## Product Purpose

A product showcase for `dbportal` npm package that highlights its developer-first architecture, zero-setup terminal utility, multi-database inspection capabilities, and Docker container management.

## Positioning

`dbportal` is the terminal-native, single-command (`npx dbportal`) browser GUI that replaces heavy desktop clients for multi-database exploration and Docker container management.

## Conversion & Proof

- Primary CTA: `npx dbportal` (Copy terminal command)
- Secondary CTA: GitHub Repo / Discord Server
- The line a visitor remembers after 10 seconds: "Inspect databases and manage Docker containers with a single terminal command."
- Proof: GSSoC 2026 featured project, open-source MIT license, multi-database native driver suite.

## Brand Personality

Terminal-native, razor-sharp technical precision, deep obsidian dark mode, crisp high-contrast typography, high-density developer ergonomics.

## Anti-references

Saturated glassmorphic AI slop, generic blue blurred cards, rounded soft template landing pages, slow heavy desktop wrappers.

## Design Principles

- **Terminal-First Ergonomics**: Crisp contrast, monospaced metadata, tactile keybindings, and real interactive terminal simulators.
- **High-Density Utility**: Show real working UI data grids, schema visualizers, and container state managers.
- **Zero Decorative Slop**: Clean 1px structural borders, pitch black surfaces (`#090a0f`), electric lime & cyan accent highlights.
- **Tactile Bottom Dock**: Floating command dock with visible keyboard shortcuts (`[1]` to `[6]`).
